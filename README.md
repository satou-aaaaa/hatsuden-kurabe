# 発電のしくみくらべ（hatsuden-kurabe）

手がかり3枚から、発電方法（LNG・石炭・石油の火力、原子力、水力、太陽光、風力、地熱、バイオマス）を当てる1日5問の学習ゲーム。正解したら「決め手はどれ？」も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/hatsuden-kurabe/>

- 中身は資源エネルギー庁の資料（「マンガでわかる 電気はあってあたりまえ？」・エネこれ・エネルギー白書2024・「なっとく！再生可能エネルギー」・「日本のエネルギー 2025年度版」）で確かめた、発電方法ごとの特徴だけ。出典は `data.js` の `SRC` と画面の「このゲームについて」。
- 発電の割合や費用は年で変わるので、答えにしていません。どの発電方法がよいかのような、意見の分かれることは扱いません。
- このゲームは公式の情報の代わりではありません。記録は遊ぶ人のブラウザだけに残り、外へ送りません。

作業の決まりは [AGENTS.md](AGENTS.md)。
